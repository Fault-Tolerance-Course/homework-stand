# Задание 2

**Что произойдет, если limit слишком высоко?**

Если limit слишком высок, то есть риск серьезной деградации или даже падения сервиса, т.к. он перегружен и rate-limiter фактически бесполезен до тех пор, пока не превышены заданные лимиты. Как минимум, будет нарушен SLA при перегрузках.


**Что произойдет, если burst слишком велико?**

Для части запросов будет нарушен SLA, если разница limit и burst слишком велика, то есть большой риск уронить сервис огромной пачкой запросов, даже если средний RPS не выходит за рамки limit.

**Как timeout rate-limiter влияет на стабильность ручки?**

Таймаут влияет на latency, поэтому в случае большой нагрузки, часть запросов могут выходить за рамки SLA только из-за ожидания токенов по таймауту. Поэтому величина таймаута должна быть подобрана с умом, в особенности в рамках строгого SLA.

**Можно ли использовать этот лимитер для других ручек в сервисе?**

Нет. Каждая ручка уникальна по своим техническим ограничениям, SLA и критичности для бизнеса. Параметры для лимитера подбираются индивидуально для каждого хэндлера.
